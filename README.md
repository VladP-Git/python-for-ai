# python-for-ai
Hard Skills модуля для резюме 🪪
Работа с ИИ-решениями на базе LLM (GPT, BERT) с использованием LangChain и RAG (Retrieval-Augmented Generation). 
Навыки промпт-инжиниринга, работы с векторными базами данных и эмбеддингами. 
Понимание интеграции мультимодальных моделей (Whisper, CLIP, DALL-E) и разработки автономных ИИ-агентов, тонкой настройки моделей (Fine-tuning) и оптимизации работы с API (OpenAI, Hugging Face)
